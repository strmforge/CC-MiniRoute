# CC MiniRoute

Private Windows-focused fork of CC Switch for local Codex/Claude/Coding CLI routing experiments.

This fork is currently maintained as a private working copy for:

- Safer local routing experiments without pushing changes back to upstream.
- CC MiniRoute branding, icon, app links, tray entry, and update links.
- Codex provider/catalog fixes, including non-OpenAI model mapping work such as MiniMax and DeepSeek routes.
- Local compatibility work for the user's Codex, CC, OpenClaw, Hermes, and related desktop workflow.

## Current Policy

- Keep upstream as `upstream`: `https://github.com/farion1231/cc-switch`
- Keep this fork as `origin`: `https://github.com/strmforge/CC-MiniRoute`
- Do not push local experiments back to upstream.
- Keep existing local data paths compatible unless a migration is intentionally designed and tested.

## Builds

The current Windows build artifacts are generated by Tauri under:

```text
src-tauri/target/release/bundle/
```

The latest local build from this working copy produced:

```text
src-tauri/target/release/bundle/nsis/CC MiniRoute_3.16.0_x64-setup.exe
src-tauri/target/release/bundle/msi/CC MiniRoute_3.16.0_x64_en-US.msi
```
